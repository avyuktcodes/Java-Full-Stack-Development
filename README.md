# Java Full Stack Development

A collection of Java, Maven, Spring Framework, and Spring Boot modules, assignments, and practicals.

## 📁 Repository Contents

- **[Class Assignment1](./Class%20Assignment1)**: Spring Boot 5-Page Web Application (Student Management System) with static web routing, custom CSS, and Maven configuration.
- **[Maven Project](./Maven%20Project)**: Maven-based Java practicals and executable JARs.
- **[Module Project](./Module%20Project)**: Java modular programming examples.
- **[Spring Core](./Spring%20Core)**: Spring Framework core concepts including Inversion of Control (IoC), Dependency Injection (DI), and Spring MVC.

For setup and execution instructions for each module, navigate to its respective directory.
